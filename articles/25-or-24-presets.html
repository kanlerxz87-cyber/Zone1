Source forensics

25 presets, 24 presets, or 10-in-1? One brand page says all three

A single official product page contradicts itself four ways. That is not a scandal; it is what an unmaintained product page looks like. Here is how to read it.

Investigation· 4 min read· sources read 2026-11-14· Documentation-based — no hands-on testing Cluster: What do the numbers actually mean?
No hands-on testing, and no Amazon numbers

Nobody here cooked with these appliances. Every specification below is quoted from the manufacturer's own product page or owner's manual and links to it. No Amazon price, star rating or review count appears, because Amazon's Program Policies only permit those when Amazon serves the link or via Creators/PA API S2.

Products covered
  • French Door AirFryer 360 Toaster Oven Combo, 26 QT — Kitchen appliances → Air fryer toaster ovens

The four numbers, all from official sources

On 2026-11-14 the Emeril Everyday product page for the 26 QT French Door AirFryer carried 25 Cooking Pre-sets in its specification block, 24 one-touch cooking presets in its description paragraph, and a feature heading reading 10-In-1 Versatility. One of its carousel images is a file named `11-in-1_convection_oven_in_action.png`. Amazon's listing title for the same product says 24 cooking functions.

Five official statements, four different numbers, one product.

Sources for this section: S14 S16

The manual is the tiebreaker a shopper can actually use

The owner's manual linked from that same page names 24 presets for model FAFO-001, listed one by one: Airfry, Fries, Bacon, Grill, Eggs, Fish, Ribs, Defrost, Steak, Vegetables, Wings, Bake, Rotisserie, Toast, Chicken, Pizza, Pastry, Proof, Broil, Slow Cook, Roast, Dehydrate, Reheat, Warm.

That is a countable list on the document that ships with the unit, and it agrees with the description text and with Amazon. It does not agree with the page's own specification block.

Sources for this section: S15 S14

What this means for a buyer

Nothing about the appliance changes when a marketing page is wrong. What changes is how much of the page you should trust. A page with four different preset counts, placeholder copy in its help section, and a carousel asset named for a feature its own heading contradicts is a page that was assembled quickly and not re-read.

The specifications that are singular and specific on that page — the dimensions, the 24.6-litre capacity and the 120-volt rating stated in that same block — are the ones to plan around, because a copy-paste error is less likely to survive in a field a shipping department needs.

Sources for this section: S14

Why the site still shows no preset count for this product

Because two official sources agreeing is not the same as the manufacturer publishing one number. The owner's manual names 24, so the specification row is published against the manual and not against the marketing page — and the conflict is published on the Flagged for review page so you can see exactly what was reconciled and what was not.

Sources for this section: S15 S14

The manual's 24-preset list is countable and is cited to the manual. The 25, 24, 10-in-1 and 11-in-1 statements are all published verbatim on the brand's own page and are recorded on the Flagged for review page rather than smoothed over.
