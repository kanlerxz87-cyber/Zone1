Why this site does not show Amazon prices or star ratings

There is no live price feed here. Leaving those fields out is a deliberate limit, not a claim that the retailer has no price.

Policy explainer· About 2 min read· Edited 2026-11-19· Documentation-based — no hands-on testing Cluster: Can this page be trusted with my money?

AI-assisted, document-based writing. No hands-on testing or live Amazon price/rating feed. How this publication is made.

Prices need an authorised route

Amazon’s Participation Requirements limit price and availability display to the circumstances in section 2(b): Amazon serves the link containing that information, or the publisher obtains it through Creators API or PA API and follows the applicable requirements.

This publication has no enabled Amazon data integration. It therefore does not transcribe a price from a product page and present it as a current Amazon offer.

Sources for this section: S2

Reviews have a separate rule

Section 6(t) restricts display of Amazon customer reviews and star ratings unless the required link is obtained through the official API and the API requirements are met. A manufacturer’s review widget is a different source; it would not turn into an Amazon rating by being placed beside an Amazon link.

No customer-rating leaderboard is used on the buyer pages. The documents do not support an independent quality ranking.

Sources for this section: S2

A dated brand price is not today’s checkout price

The evidence dataset retains dated manufacturer list-price observations. They are not live retailer offers, availability checks or a promise about what a reader will pay. The buying summaries lead with the documented format and specifications instead.

Sources for this section: S10 S12 S14

No price alert is being quietly run

Section 6(y) prohibits price tracking or alerts unless Amazon agrees otherwise. This site has neither feature. To check an offer, open the retailer deliberately, verify the exact variant and read the price and terms there. The supplied-link identity and attribution questions remain separate.

Privacy, cookies & local-only decision storage

This site sets no cookies itself, runs no analytics, and has no public accounts, comment forms or email-signup form. The analytics client is implemented but is not loaded: no production collector is deployed. No production event counts have been measured by this site.

The owner-only decision picker stores choices in this browser’s local storage. It sends nothing automatically; choices leave the page only when explicitly copied or downloaded. Use its clear button to remove the saved choices.

Hosting is separate: GitHub states that Pages logs visitors’ IP addresses for security. Any future analytics host or proxy also needs its own logging and retention review. Following an Amazon link takes you to Amazon, where Amazon’s privacy notice and cookie practices apply.
