Sync Finish, explained by the manual that ships with it

One button promises two baskets that end at the same time. The owner's manual spells out exactly how that works, exactly when it breaks, and what the other sync button does instead.

What Sync Finish does, in the manual's own words

The TurboFry Touch dual-window model publishes the feature as: Yes — delays the start of the shorter cook so both baskets finish together; a separate Sync Baskets function copies time and temperature to the second basket. That is this site's condensed record; the owner's manual describes the same behaviour step by step.

To use it, both baskets are set to their own times and temperatures, the SYNC FINISH button is pressed, and the unit starts the side with the longer cook first. The manual states that it delays the start of the other side until the appropriate moment so that they finish together, and that the basket which is waiting displays HOLD on the panel until it begins.

Sync Baskets is the second button, and it does something different: it applies the time and temperature set on the first basket to the second, so both baskets cook identically rather than finish together. The manual calls it a shortcut for setting both baskets to cook simultaneously with the same time and temperature.

How each one behaves once cooking starts

Under Sync Baskets, an adjustment made to one basket while cooking is applied to the other automatically, so the two stay matched. Under Sync Finish, an adjustment made while one basket is still waiting keeps the finish synced, provided the shorter cook time is not raised above the longer one.

The pause behaviour is documented too: when either basket is pulled out during cooking, both sides pause until it is returned. The SHAKE light comes on as a reminder to shake or flip food, and goes off on its own after about a minute if the basket is not pulled out.

Sources for this section: S18

What breaks the sync

Two documented actions break it. Pressing the HI-FRY button — the one that raises the cooking temperature to 450 °F / 235 °C, held for 2 minutes, for extra browning — lifts one basket out of the shared schedule: in the sync modes, the manual says pressing it raises the temperature only on that basket and breaks the sync. The +2 MIN button does the same.

The manual adds a detail worth knowing before a second batch: while the unit cooks on one side, the other basket can still be started later, but the SYNC BASKETS and SYNC FINISH functions will not be available for that cook.

Sources for this section: S18

What this feature is not

It is not a promise about doneness. Finishing at the same time is a scheduling behaviour documented by the manufacturer; whether each basket is cooked through is still a check the cook makes, and the manual's own advice is to check foods for doneness against current safety guidelines before serving.

It is also not a feature of every machine in this set. The manual for the 8 Qt TurboFry Touch — which this site also reads — lists one basket in its features section, so there is no second basket for two buttons to coordinate; the sync functions are documented only on the dual-window model's manual. That difference is recorded in the dataset as not documented for RJ38-SQSS-8T on the brand page or in its manual, on the row that asks whether a basket divider exists for the 8 Qt model.
