Link policy constraints

#RulePractical effectSource
L1 Links must use the “tagged” Special Link formats Amazon provides (OA §1). Build links with your tag via SiteStripe / Link Tools / PA API — not hand-untagged URLs. Operating Agreement §1
L2 Shortening is allowed but “you will not use a link shortening service … in a manner that makes it unclear that you are linking to an Amazon Site” (§2(w)). Prefer a.co / amzn.to (Amazon's own shorteners). The provided link.amazon links fail this clarity test for our readers → replace before publishing. Policies §2(w)
L3 “You will not cloak, hide, spoof, or otherwise obscure the URL” containing Special Links (§2(v)). No redirect layers that hide the Amazon destination. Policies §2(v)
L4 “Redirecting Links” that route users to Amazon via an intermediate page without affirmative action are disqualified (Commission Income Statement §2(e)). Clicking our link goes straight to Amazon — no interstitial hops. Commission Income Statement §2(e)
L5 “You must not encourage customers to bookmark your Special Links” (§2(b)). No “save this link” prompts. Policies §2(b)
L6 No Special Links in content placed on Amazon sites (reviews, lists, forums) (§2(p)); no posting them on Amazon to promote them (§2(b)). Links live only on our Site and approved channels. Policies §2
L7 Special Links in email/SMS/DM only if the recipient opted in (§4). Newsletter placement requires confirmed opt-in list. Policies §4
L8 Sub-tag tracking IDs may be issued “upon your request but subject to our approval” to monitor performance — but may not be dynamically assigned per end user (§2(b)). Static sub-tags per campaign/page are OK; per-visitor tag assignment is not. Policies §2(b)
L9 Prohibited Paid Search Placement: no buying ads on “amazon”, “kindle” or other Amazon marks as keywords (CIS §2(c)). Paid search campaigns exclude brand terms. Commission Income Statement §2(c)

Build-a-link quick reference

  • Canonical product link: https://www.amazon.com/dp/<ASIN>
  • Tagged Special Link: https://www.amazon.com/dp/<ASIN>?tag=<YOUR-ASSOCIATE-ID>-20
  • Amazon's shorteners: https://a.co/d/<code> (Associates) · https://amzn.to/<code> (consumer sharing) — both resolve to amazon.com.
  • Never: untagged links in monetized content, third-party cloakers, per-user tags, or links that obscure the Amazon destination.

Short-domain formats reported by public documentation; the authoritative tag format is Policies §2(b) (source linked in the table above).
