Key irregularities (all flagged, none blocking).

  • The provided IDs are 9 characters; Amazon ASINs are 10 characters (sources: PA API 5.0 docs, KDP help). Direct amazon.com/dp/<ID> lookups return “Page Not Found”.
  • The link.amazon short-link domain is not documented among Amazon's published short-link domains; its provenance is unconfirmed, though its redirects are stable and land on official amazon.com pages.
  • Commission rates: fixed category rates are published in the public Standard Commission Income Statement (verified: Table 1 — Kitchen 4.50%, All Other Categories 4.00%), but Amazon does not publish which table row an air-fryer ASIN maps to, and /help/operating/schedule shows an account-specific rate card. Per-product rate cells stay blank and flagged — never guessed.
  • Prices and star ratings are not republished on this site: Associates Program Policies restrict displaying them to Amazon-served links or PA API/Creators API data. Blank cells cite the rule.

Data-integrity rules used throughout

  • Every table row links to an official source (amazon.com, affiliate-program.amazon.com, webservices.amazon.com, kdp.amazon.com, ftc.gov).
  • If a value cannot be confirmed from an official source, the cell is left blank and flagged — never inferred or filled.
  • Observed values (e.g., redirect targets) are dated; volatile values are labelled as observations, not facts about the future.
  • Restricted values (prices, star ratings) are withheld by policy and marked with the governing rule.
