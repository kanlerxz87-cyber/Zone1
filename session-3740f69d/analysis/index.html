4. Commission potential

Why per-product commission values are blank. Fixed category rates ARE published — verified 2026-11-13 in the public Associates Program Standard Commission Income Statement (Table 1: Physical Books / Kitchen / Automotive 4.50%; Home, Home Improvement … 3.00%; All Other Categories 4.00%). What Amazon does not publish is which table row an air-fryer ASIN maps to (Kitchen vs. Home vs. All Other), and /help/operating/schedule additionally redirects to an account-specific rate card. The per-product rate is therefore recorded as unverified with candidate rows — never selected by guess (flag F4).
