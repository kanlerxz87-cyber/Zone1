publish which category a given ASIN is assigned to. "Kitchen" is the only row this project can name for

about the ASIN. The site therefore keeps the per-product rate blank and shows the candidate rows (F9 /
data/products.json → `commission.candidate_rows`). It does not multiply anything by 4.50% and call it
expected revenue.

**Requirement-by-requirement:**

| Requirement | Official source | How the marketing layer satisfies it |
|---|---|---|
| State "As an Amazon Associate I earn from qualifying purchases." clearly and prominently | Operating Agreement §5 (S1) | Injected by `layout()` into every page's disclosure bar, above the navigation. | Link-level clear + conspicuous disclosure | S1 §5; FTC Disclosures 101 (S8) — "place it so it's hard to miss" | Every CTA carries a "Paid link" badge and a sentence naming the commission and its cost to the reader. Each article opens with a disclosure callout before the first body paragraph. |

The build gate rejects `Amazon price:` and the article gate rejects rating patterns. Manufacturer list prices are quoted only in the product pages, labelled as the brand's own list price with its source. |
| No customer reviews or star ratings except via the API | Program Policies §6(t) (S2) | Manufacturer review-widget ratings are shown on product pages with an explicit note that they are the brand's widget, not Amazon's; no Amazon rating appears anywhere. The article layer shows none. |
| Do not alter Program Content | Program Policies §6(a) (S2) | Amazon listing titles are reproduced verbatim with a source badge. Nothing is truncated in a way that changes meaning; where only a fragment is quoted it is marked as a quotation. |
| No link shortening that obscures the Amazon destination | Program Policies §6(w) (S2) | Links to Amazon are the supplied `link.amazon` short links (which keep the Amazon name) and plain `/dp/<ASIN>` URLs in source badges. No third-party shortener is used. |
| No price tracking or alerting | Program Policies §6(y) (S2) | No such feature exists; the platform blueprint lists it as out of scope. |
| No ML training on Program Content | IP License §5 (S2) | The article generator consumes `data/products.json`, which is built from manufacturer pages and manuals — not from Amazon Program Content. Stated on `platform.html`. |
| Do not describe untried experience | FTC Disclosures 101 (S8) | Standing notice on every article; the words "tested"/"we tried" appear only in the negative. |
| Material connection disclosed clearly and conspicuously | 16 CFR §255.5(a) (S9) | Disclosure bar + article callout + CTA note, all above the content they qualify. |
