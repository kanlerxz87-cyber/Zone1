Click & conversion tracking

A working tracking layer for the link layer: every click on a managed affiliate link is recorded (per browser), conversions can be marked, and the data exports as JSON. The honest boundary is documented below: on a static host, Amazon Associates reports are the source of truth for conversions and commissions — anything else is a local approximation.

Dashboard

Data lives in your browser's localStorage only. Generate clicks via the test buttons on the Link Manager (clicks on those buttons are recorded without leaving the page).

Production architecture (documented, not simulated)

  1. Outbound: site CTA → own redirect endpoint /go/<link-id>?src=<page> that logs (id, page, referrer, timestamp, user-agent class) then 302s to the tagged Special Link.
  2. Storage: append-only log (e.g. object storage or a small database); raw events kept, aggregates computed.
  3. Conversions: reconcile with Amazon Associates' daily reports (order IDs are not exposed to links, so reconciliation is statistical: clicks → ordered items → shipped items per link window).
  4. Privacy: IP truncation/short retention, no cross-site tracking, consent where legally required (GDPR — the owner is in Norway; flag F08).
  5. Optimization loop: per-link CTR/CVR/EPC feeds the campaign optimizer on Analysis §6.
