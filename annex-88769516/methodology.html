Verification Methodology

Every table row on this site must trace to an official source. Where a value could not be confirmed from an official source, it is left blank and flagged UNVERIFIED — never inferred or filled.

Principles

  • Official sources only — product data from Amazon; policy/commission data from the Amazon Associates pages on affiliate-program.amazon.com.
  • No inference — if a value cannot be confirmed, it stays blank and is flagged.
  • Line-by-line — each value is checked against its cited source before publication.
  • Irregularity flagging — any blocker or contradiction is published on the Flagged for Review page.

Routes attempted for product verification

  • Direct Amazon pages (/dp/, /gp/product/, /gp/aw/d/) on amazon.com — bot-blocked (Dogs of Amazon).
  • Other marketplaces (amazon.co.uk, amazon.de) — 404 / homepage redirect.
  • Reader & render proxies (Jina reader, microlink real-browser) — bot-blocked; even a known-valid ASIN returns 404 (calibration).
  • CORS proxies (allorigins, codetabs, corsproxy) — timed out / 403.
  • Archives (Wayback availability + CDX) — no snapshots for the ASINs.
  • Search engines (Bing, Google) — no relevant results for the ASINs.
  • ASIN trackers (CamelCamelCamel, Keepa) — no valid record / "invalid product identifier".
  • Provided link redirect chains — marketplace fallback to different ASINs.

The Amazon Associates affiliate-program.amazon.com help pages were reachable and verified for commission and compliance content.
