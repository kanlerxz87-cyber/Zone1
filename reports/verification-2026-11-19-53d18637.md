Browser requests use fixed same-origin HTTPS JSON, `credentials: omit`, `no-referrer`, DNT/GPC
suppression, and no persistent reader IDs or browser storage. The application stores only
UTC-day event aggregates with allowlisted IDs, not raw events, IPs, agents, full URLs or
referrers. Host/proxy logging is a separate responsibility. Origin is not authentication;
network events can be forged and blocked/opted-out readers are undercounted.

All production runtime/privacy/log/receipt gates are false, both switches are false and the
endpoint is blank. No persistent authorized host or production receipt exists. The real
campaign ledger has **no rows**; that is not a claim of zero real orders. Tests use temporary
databases/ledgers and a navigation-suppressed, synthetic product-URL fixture. They do not
