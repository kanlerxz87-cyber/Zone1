## 1. Method

1. Each published value was matched against the **official source the site cites for it** — not against a
   summary of it, and not against another session's note.
2. A value is *confirmed* only when the source states it outright. A source that is silent, or two
   sources that disagree, produces a **blank row plus a flag**, never an inferred value.
3. Control tests were run on every behaviour that a reading could have got wrong (a 9-character token
   treated as an ASIN; a nonsense token treated as a short link).
4. Where this pass disagreed with an earlier pass, the earlier finding was re-fetched first and the
   disagreement was resolved on the evidence, not on seniority.
