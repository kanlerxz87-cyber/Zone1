What this site collects

Nothing. There are no cookies, no analytics, no pixels, no tracking scripts, no third-party fonts and no forms. The pages are static files served by GitHub Pages. There is no account, no newsletter and no comment system.

What GitHub collects

The site is hosted on GitHub Pages. GitHub logs requests, including IP addresses, as part of serving the site. That processing is GitHub's and is described in GitHub's own privacy statement at docs.github.com ↗.

What happens when you click an outbound link

Product links go to amazon.com. Once you leave this site, Amazon's privacy notice and cookie practices apply, not mine. If an Associates tag is configured, the click carries that tag as a URL parameter so Amazon can attribute a resulting purchase. As an Amazon Associate I earn from qualifying purchases.

Amazon's requirement on disclosure of tracking

Amazon's Program Policies require a site to disclose, accurately and adequately, its own use of cookies, pixels and other technologies. Because this site uses none, the honest disclosure is the one above. Source: Amazon policies ↗ · Participation Requirements §3(e).
