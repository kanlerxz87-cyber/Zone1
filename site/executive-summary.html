1. What was delivered

A static, GitHub-Pages-hosted dashboard covering three Amazon air-fryer affiliate products. It publishes a verification register in which every fact carries the official page it came from, a compliance register quoting Amazon's and the FTC's own requirements, three buying guides reasoned only from verified specs, and a review queue of 17 flagged items.

3. The headline finding

Chefman TurboFry 8 Qt scores highest on merchandising fit (82.8), but the single most important finding in this audit is not a product ranking. It is that Amazon's Program Policies restrict showing prices, availability, reviews and star ratings to data Amazon serves or data obtained through its API. This site therefore publishes no Amazon prices and no Amazon ratings. Every such cell is blank and links to F-08. Most affiliate sites fill those cells in anyway. That is the compliance risk this build removes.

4. The blocker

No Associates tag is configured, so no link on this site can currently earn. One value in data/config.json and a rebuild converts every outbound link into a tracked Special Link. Until then the site displays a warning on every page (F-10). This is the highest-value action available and it costs about a minute.

5. Evidence quality, honestly stated

Solid

  • Capacity, wattage, temperature range, function counts, certifications and warranty for both Chefman units — read off Chefman's own product pages with model numbers matching.
  • The Amazon commission rate and the attribution windows — read off Amazon's own published documents.
  • The disclosure requirement — quoted verbatim from the Operating Agreement §5.

Weak or absent

  • Demand data. No official source exists for search volume, sales rank or conversion rate. The fit score is a merchandising ranking, not a demand forecast.
  • The Emeril unit. Wattage and safety certification unconfirmed (F-09); three conflicting preset counts (F-03).
  • Review sentiment. Only brand-storefront ratings were reachable, and those are not comparable to marketplace ratings (F-12).
  • Link fidelity. All three short links landed via a fallback marker (F-01).

6. Compliance posture

Twenty requirements are recorded with the operative quote and the specific implementation. Five things were deliberately not built because Amazon prohibits them: price tracking and price alerts (§3(y)), Amazon price/rating display without API data (§2(b), §3(t)), cloaked or shortened outbound links (§3(v)), click incentives (§3(g)), and any use of Amazon logos or brand imagery. See the compliance register.

7. Recommendations, in priority order

  1. Set the Associates tag and rebuild. Nothing earns until this is done.
  2. Re-check the three short links in a browser and replace them with canonical tagged /dp/<ASIN> URLs (F-01).
  3. Apply for Creators API / PA API access. This is the only lawful route to showing Amazon prices and ratings, and it is what would make the comparison table genuinely useful (F-08).
  4. Resolve the Emeril wattage and certification from the manual or the rating label before publishing any claim about it (F-09).
  5. Get the Chefman 6 Qt model number confirmed against the Amazon SKU to settle the “Hi-Fry” discrepancy (F-02).
  6. Only then build the click counter and read conversions from the Associates dashboard. Do not build a price tracker, ever.
