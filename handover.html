Handover

Five actions, about an hour, a handful of flags

Everything in this repository is done as far as it can be done without the account holder's own logins. These five actions are the shortest path from "unverified" to "confirmed". Each shows the time it takes and the flags it closes.

H1 is done — by a fetch, not by hand. All three listings' Product information blocks were read on 2026-11-16 (F68, F49): B0CDY277D3 = RJ38-SQPF-3TDB-2W, B08DKYBTPH = RJ38-SQSS-8T (in its Part Number row), B09B7SB46R = 4-00675-02X-VN, which is one character from the brand page's string and is the remaining conflict (F70). What H1 was going to settle is settled for the model step; what it could never settle is the intent behind the three supplied short links, your Associates tag and your account data — those are still the top of the list here.
H1

Open each of the three supplied links on a desktop browser and read the Model number line in the listing's “Product information” section.

3 minutes

This is the single highest-value action in the project. The site currently shows a candidate ASIN and a “believed” manufacturer SKU; this line makes the mapping a fact instead of a match. It cannot be done by a headless fetch, which is why it is still open after seven sessions.

What cannot be done from here

  • Auto-approval of an Associates account, or viewing its reports.
  • Reading an ASIN's Product-information block reliably (the listing pages render it client-side).
  • Publishing a real Amazon price, availability, star rating or review count (S2 §2(b), §6(t)).
  • Calling Creators API / PA-API without credentials tied to the account (F12).
  • Registering a domain or a Search Console property.

When the answers come back, they are recorded in the flag register with their source and the date read, not inferred from an earlier pass. Every published value on this site carries that same discipline.

Privacy, cookies & local-only decision storage

This site sets no cookies itself, runs no analytics, and has no public accounts, comment forms or email-signup form. The analytics client is implemented but is not loaded: no production collector is deployed. No production event counts have been measured by this site.

The owner-only decision picker stores choices in this browser’s local storage. It sends nothing automatically; choices leave the page only when explicitly copied or downloaded. Use its clear button to remove the saved choices.

Hosting is separate: GitHub states that Pages logs visitors’ IP addresses for security. Any future analytics host or proxy also needs its own logging and retention review. Following an Amazon link takes you to Amazon, where Amazon’s privacy notice and cookie practices apply.
