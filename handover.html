Handover

Five actions, about an hour, a handful of flags

Everything in this repository is done as far as it can be done without the account holder's own logins. These five actions are the shortest path from "unverified" to "confirmed". Each shows the time it takes and the flags it closes.

H1 is done — by a fetch, not by hand. All three listings' Product information blocks were read on 2026-11-16 (F68, F49): B0CDY277D3 = RJ38-SQPF-3TDB-2W, B08DKYBTPH = RJ38-SQSS-8T (in its Part Number row), B09B7SB46R = 4-00675-02X-VN, which is one character from the brand page's string and is the remaining conflict (F70). What H1 was going to settle is settled for the model step; what it could never settle is the intent behind the three supplied short links, your Associates tag and your account data — those are still the top of the list here.
H1

Open each of the three supplied links on a desktop browser and read the Model number line in the listing's “Product information” section.

3 minutes

This is the single highest-value action in the project. The site currently shows a candidate ASIN and a “believed” manufacturer SKU; this line makes the mapping a fact instead of a match. It cannot be done by a headless fetch, which is why it is still open after seven sessions.

Closes
F1, F32, F33

Three model numbers, one per link. S16 S28 S29
H2

In Associates Central, open Manage Tracking IDs and read the tracking ID, then confirm that the three supplied links carry it. If they do not, rebuild each link from the Product Linking tool. [Updated 2026-11-17: the confirmation that counts is a row in the Tracking ID Summary Report (S42), not a look at a link's destination — see Q-28 and SG-37 for the exact five minutes, and F76 for why the tag stays unapplied until they pass.]

5 minutes

As supplied, none of the three landing URLs shows a tag= parameter. A purchase through an untagged link does not credit the account. Tagging is also a requirement for the application review, which is final once rejected (S4).

20 minutes, plus registrar time

GitHub Pages serves the site today and the canonical URL is baked into sitemap.xml and robots.txt. Moving to a real domain is a five-line change in build.py, but the Search Console property is yours alone.

What cannot be done from here

  • Auto-approval of an Associates account, or viewing its reports.
  • Reading an ASIN's Product-information block reliably (the listing pages render it client-side).
  • Publishing a real Amazon price, availability, star rating or review count (S2 §2(b), §6(t)).
  • Calling Creators API / PA-API without credentials tied to the account (F12).
  • Registering a domain or a Search Console property.

When the answers come back, they are recorded in the flag register with their source and the date read, not inferred from an earlier pass. Every published value on this site carries that same discipline.

Privacy & site technologies +

This site sets no cookies itself, runs no analytics, and has no comment forms or accounts. This GitHub Pages build sends no analytics events: the proposed first-party collector is not deployed and browser collection remains disabled. Following an Amazon link takes you to Amazon, whose own privacy notice and cookie practices apply from that point. No data you enter on reader pages is collected. The owner-only decision picker stores drafts in your own browser, only when used; it does not submit them. GitHub Pages may retain connection logs for security under its own privacy policy.

Amazon's Program Policies §3(e) require an accurate statement of cookie and third-party technology use on Associate sites. This notice describes this build; it is not a legal-compliance determination and must be reviewed the moment any analytics, embeds or affiliate-network script is added. The outbound-click counter for this site is written and shipped in assets/analytics.js but is switched off, because no endpoint host has been chosen — no analytics request is sent. Hosting still entails connection metadata. The paragraph above is generated from that switch, so it cannot describe a behaviour the page does not have.
