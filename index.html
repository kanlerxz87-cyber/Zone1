What this project does

  1. Resolve — the three supplied link.amazon URLs are followed to their canonical amazon.com/dp/<ASIN> destination and the product identity confirmed from the page title. F-01
  2. Verify — every attribute is read from the live official page. 3 ASINs, 99 attributes, 85 confirmed, 14 left blank.
  3. Analyse — pricing, review depth, competitive set, demand velocity and commission potential are modelled from the verified values only.
  4. Generate — SEO article, head-to-head comparison and buying guide, each carrying the required Amazon and FTC disclosures inline.
  5. Operate — link templates with a publisher tag, a sub-tag measurement scheme, and a re-verification schedule that keeps price and badge claims compliant.
  6. Govern — 28 program rules mapped to this site, 8 automation rules, and 13 irregularities published for review rather than silently resolved.

Verification standard applied

Every value in this file was read directly from an official first-party source (amazon.com product/search pages, affiliate-program.amazon.com policy pages, ftc.gov). Where an official source did not serve a readable value, the field is null and carries an unverified flag. No value is inferred, estimated or filled in from memory.

One standing caveat. Amazon Associates Program Policies restrict displaying Product prices and star ratings unless they are served by Amazon alongside the link or obtained through Creators API / PA API. This site is a static research build, so those values are dated snapshots of official pages, not licensed Product Advertising Content.
