How the verification works

1

Resolve

Follow the short link, record the ASIN it lands on and the page title. Log the fallback marker if present (F-01).

2

Cross-read

Find the same model on the brand's own storefront. Compare field by field. Where the two disagree, publish the disagreement instead of choosing a side (F-02, F-03, F-04).

3

Record

Each value goes into a JSON file with a status of verified, flagged or unverified. A blank value is only legal for an unverified row.

4

Assert

A build script generates every page from that data and a verifier fails the build if any row is missing a source.
