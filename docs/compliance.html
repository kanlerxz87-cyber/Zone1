Compliance matrix

23 requirements, each with a verbatim quotation and a link to the official Amazon or FTC page it came from. Where a requirement could not be read from a public official page, the row says so and is marked unverified.

Policy versions read on 2026-11-13: Amazon Associates Program Policies — updated April 14, 2026; Associates Program Operating Agreement — updated October 15, 2025; 16 CFR Part 255 — eCFR current as of 2026-11-10; 16 CFR Part 465 — eCFR.

How this site satisfies the disclosure requirement

The disclosure bar at the top of every page carries the exact sentence Amazon requires, and the same sentence is repeated immediately above every block of affiliate links, so it is never behind a click or a scroll-to-footer (C1, C3, C6). The site never uses "buy now" or "affiliate link" as its only disclosure (C5).

The footer of every page carries Amazon's required trademark statement (C12): Amazon and the Amazon logo are trademarks of Amazon.com, Inc. or its affiliates.

Why there are no prices on this site

Amazon permits a site to display price and availability only when Amazon serves that data or when it is obtained through the Creators API / PA API (C8). This account has neither, so the site stores no prices and links out to Amazon instead. That is a compliance decision, not an oversight — and it is also why the price column reads "not stored" rather than showing a stale number.
