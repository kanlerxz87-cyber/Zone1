Privacy & site technologies +

This site sets no cookies itself, runs no analytics, and has no comment forms or accounts. This GitHub Pages build sends no analytics events: the proposed first-party collector is not deployed and browser collection remains disabled. Following an Amazon link takes you to Amazon, whose own privacy notice and cookie practices apply from that point. No data you enter on reader pages is collected. The owner-only decision picker stores drafts in your own browser, only when used; it does not submit them. GitHub Pages may retain connection logs for security under its own privacy policy.

Amazon's Program Policies §3(e) require an accurate statement of cookie and third-party technology use on Associate sites. This notice describes this build; it is not a legal-compliance determination and must be reviewed the moment any analytics, embeds or affiliate-network script is added. The outbound-click counter for this site is written and shipped in assets/analytics.js but is switched off, because no endpoint host has been chosen — no analytics request is sent. Hosting still entails connection metadata. The paragraph above is generated from that switch, so it cannot describe a behaviour the page does not have.
