Suggestions: choose the path before anything changes

12 suggestions to improve the site's design, trust, content and measurement. None of them has been implemented. Each one lists the options. Pick an option for each ID you want, and only then will the change be made.

How to decide. Each row has a basis. Where the basis is an official Amazon or FTC source, the link goes to that source. Where the row is a design opinion, it says so and points to Flagged for review. The options run from the current state (A) to the recommended path.

SG-05
Content
 Write only from facts you can source, and state any first-hand experience only if the owner actually uses the product. Do not write reviews for products that have not been tried. FTC Disclosures 101: you cannot talk about your experience with a product you have not tried; a paid recommendation cannot say a product is great if you thought it was terrible.
