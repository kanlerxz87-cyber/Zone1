Decision drafts, current states and action history

The suggestion queue runs to 60 entries, and a queue nobody closes is a backlog. This page is the closing mechanism: one picker per suggestion, the default that applies if nobody answers, and an export that turns picks into the file the next agent pass reads. The rule is computed from the same registers the suggestions live in, so the page cannot promise a default its own data does not support.

The standing rule.

A suggestion whose recommended path is reversible, low-risk, and does not depend on a fact only an Amazon account holder can supply is treated as pre-approved: the next agent pass implements it and records what it did on this page. Everything else holds until the owner picks. This exists because the brief says no manual input is required of the owner, while also requiring that a human reviews suggestions before changes - so the review has a default outcome rather than a veto that blocks the work.

What silence never authorises. Silence never authorises: spending money, registering a domain, contacting Amazon or a brand on the owner's behalf, publishing an Amazon-served price or star rating, changing a compliance posture, deleting another session's committed evidence, or asserting any product fact the repository has flagged as unverified. Anything in that class waits, on this page, with its reason.

auto-adopt requires: an option letter the suggestion recommends; that option marked reversible; that option's risk 'none' or 'low'; and no blocking question in state 'unknowable'. The four tests are computed from data/suggestions.json and data/questions.json at build time, so the table on the page cannot claim a default its own data does not support.

How a choice becomes work

  1. Pick the path on decision-log.html. The page stores it in this browser so a second visit shows the same answer.
  2. Press 'Copy decision record' (or 'Download decision-log.json') and send the text back in any session, or commit it over this file.
  3. The next agent pass reads data/decision-log.json before it reads suggestions.html's defaults, records what it implemented, and marks the row. Anything you did not pick keeps the default this page shows today.
