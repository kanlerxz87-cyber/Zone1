Profitable niche framework

Niche selection is driven by the verified official commission table plus demand and conversion signals. Commission rate is the one input currently available from an official source — demand and conversion inputs require a defined product category, which the submitted links do not provide (why). The framework below is what the platform runs; product-level niche rows stay blank until verified.

Those inputs are exactly what is missing today — so no niche is recommended for the submitted products yet (their categories are unverified).

4 · Automation pipeline for niche discovery (runs once inputs exist)

  1. Discover — pull category-level demand signals (search volume, trend slope) and top-converting listings via Creators API (PA-API 5 is deprecated — H-01) and trend tooling.
  2. Score — apply the weighted model above; exclude 0.00% categories and policy-risk categories.
  3. Validate — confirm rate rows against the official table at each refresh (rates change).
  4. Publish — generate the content for winning niches; attach tagged links.
  5. Optimize — feed click/conversion data back into the score; retire underperformers.

Everything that can run without external credentials already runs (steps 3–5 with local data); steps 1–2 need the access listed in flag F11.
