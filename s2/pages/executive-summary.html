Executive summary

Important details of the project: what was verified, what could not be, and what unblocks it.

Advertising disclosure. As an Amazon Associate I earn from qualifying purchases. This site is a demonstration platform; it currently publishes no live affiliate links.

Conclusion

A working, compliant affiliate platform scaffold with a live verification dashboard — and a hard stop on the three products, because the links supplied do not identify any product.

What was established

  • 1. The three links cannot be turned into products. Each token is 9 characters where Amazon requires 10, and each direct catalog lookup returns Amazon's 'Page Not Found' page. Nothing about the products — name, price, rating, competition or commission — can be stated without inventing it, so every one of those cells is blank and flagged. source ↗
  • 2. The other session's 'resolved' ASINs are an artifact, not a resolution. Both tokens produced a URL carrying lv=shuf and plpRedirect=mhFallback — Amazon's fallback shuffle — and two different tokens produced two different 'featured' items. A shuffle is not a mapping, so no product was attributed. source ↗
  • 3. The compliance layer is the part of this brief that could be fully verified, and it is: 25 policy constraints read straight out of the Operating Agreement and the Program Policies, each with the quoted text, the source URL and the code guard that enforces it. source ↗
  • 4. No commission rate appears anywhere on this site. The only official rate source is the signed-in rate card; the public appendix URL redirects to sign-in. Earnings are therefore expressed as a formula whose rate input is explicitly unset. source ↗
  • 5. 'AI-powered' is scoped deliberately. Amazon forbids using Program Content or Special Links to train models without written approval, so the engine uses a model to draft and structure copy, never to invent product facts, and the build fails if a draft contains an unsourced number. source ↗
  • 6. 33 unit tests pass and the data audit returns zero errors. The audit is what enforces 'every row has a source' as a build gate rather than a promise. source ↗
  • 7. Unblocking needs exactly three things from you: 10-character ASINs, your Associates ID, and PA-API credentials. The pipeline is written to accept all three without further code changes. source ↗
