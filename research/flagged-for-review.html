I-1 — Short link code looks like an ASIN but is not one

The supplied short link ends in 'B00hJ57DV', which is shaped exactly like an Amazon ASIN (B00 + 7 characters) and resembles 'B00HJ57DV'. It resolves to ASIN B08DKYBTPH. link.amazon codes are opaque, so this is not an error in the link — but any human or script that assumes the short code is the ASIN will resolve the wrong product. Recorded so nobody re-uses the short code as an identifier.

Affects: P3

Action required: No link change. Do not treat short-link codes as ASINs in any downstream tooling.

    I-2 — None of the three supplied links carry an Associates tracking tag

    All three short links resolve to Amazon URLs that contain no tag= parameter (they carried only lv, btn_ref, channelId and plpRedirect parameters).     I-3 — link.amazon short links cannot be audited before the click

    link.amazon is an opaque redirector. There is no public registry mapping a short code to an ASIN or to an owning account, so a short link's destination and its tag can only be observed by following it. Every link on this site was resolved and recorded on 2026-11-13, but that resolution is a point-in-time observation, not a guarantee.

    Affects: P1, P2, P3

    Action required: Replace short links with full tagged /dp/ URLs so the destination and tag are visible in the HTML.
