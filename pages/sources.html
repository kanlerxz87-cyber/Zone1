Sources & Verification

The audit trail. Every source used, every link resolved, every attribute checked and where the data came from. Nothing on this site is sourced from a secondary blog, a price-tracking site or memory.

Verification policy

Every value in this file was read directly from an official first-party source (amazon.com product/search pages, affiliate-program.amazon.com policy pages, ftc.gov). Where an official source did not serve a readable value, the field is null and carries an unverified flag. No value is inferred, estimated or filled in from memory.

Snapshot date: 2026-11-13. Verification method: each cited page was requested over HTTP, the response body read directly, and the value transcribed verbatim. Where the same attribute was served differently across requests, both values are recorded and the discrepancy is flagged rather than resolved by preference.

How to re-run this verification

  1. Request each supplied URL and follow the redirect chain; record the final /dp/<ASIN> path and read the destination page title.
  2. Request each amazon.com/dp/<ASIN> page and read, in order: the buy box (price, list price, discount badge), the rating and rating count, the "bought in past month" line, the About-this-item bullets, and the Product information and Item details blocks (model, UPC, capacity, dimensions, weight, wattage, Best Sellers Rank, warranty).
  3. Request the Amazon search listing for the ASIN as a cross-check — it exposes price, list price, rating, rating count and purchase velocity even when the detail page body is reduced.
  4. Read the Amazon Associates Program Policies and Operating Agreement, and the FTC's Disclosures 101 and Endorsement Guides FAQ, for the compliance map.
  5. Reconcile the transcript against data/products.json and data/program.json. Any field that cannot be re-read is set to null with an unverified flag; it is never filled from a previous run.
  6. Regenerate the site with python3 tools/build_site.py and run python3 tools/check_links.py.
